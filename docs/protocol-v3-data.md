# V3 公共数据与首次评测冻结协议

冻结日期：2026-10-04 Asia/Shanghai；本协议在获取新数据数值、训练模型及查看新留出分数之前写入。协议文件的 SHA256 和获取事件保存在 data/v3/protocol-freeze.json。此后任何修改另写修订文件，不覆盖首次冻结记录。

## 来源与用途

1. 保留 UCI Steel Industry Energy Consumption 原文件、V1 午夜工程推断审计及原行映射。使用原生 15 分钟区间 kWh / 0.25 得平均 kW；小时仅用四点能量守恒聚合。源时区未知，不替作者补写 Asia/Seoul。2018 年 12 月已经公开，只作历史回归，不作新盲测。
2. RSF 固定 2011 全站测量（OEDI submission 358）和同站天气（359），优先 https://data.openei.org/files/358/rsfmeasureddata2011.csv 与 https://data.openei.org/files/359/rsfweatherdata2011.csv。官方元数据为 CC BY 4.0。保留镜像来源和实际字节哈希。真实测量只有小时，不插值成 15 分钟；只认证小时电能费/PV场景，不认证15分钟需量。能源模型文件不是观测，不混入。
3. BDG2 作者 v1.0 固定版本的 raw electricity + building metadata。按作者 LICENSE 保守采用署名/相同方式共享；保存完整原文，不以聚合目录的 CC BY 标签覆盖它。只用整楼 electricity，不混合热量、水量等表。
4. OPSD Household Data 固定 2020-04-15 版本，15分钟数据与 datapackage。保存 CC BY 4.0、interpolated 列。固定 industrial1/2/3、public1/2；工业通道已有PV/储能且缺完整计量边界，默认 channel-only，不反推无储能总负荷、不允许收益调度。公共建筑的 grid_import 同样只证明现有表计净进口，未证明总负荷/无既有DER前仍 channel-only。

## BDG2 站点选择（先定规则，后看数值）

固定种子字符串 `nengce-v3-bdg2-first-external-20261004`。对 site_id 与 building_id 分别用 SHA256(seed + ':' + id) 排序。元数据含有 electricity 的建筑才是候选。资格条件：2016和2017各年有效、有限、非负的原始小时观测比例均 >=95%，每年正值比例 >=5%；不按模型分数、收益、峰值大小或类别美观选站。

按站点哈希序扫描，选前6个各至少有4个合格建筑的site；每个site取建筑哈希序前4个，合计24栋。前3site的12栋为development，后3site的12栋为external，site互斥。未满24栋时不降低门槛，报告实际数量与阻塞，保留候选顺序及淘汰原因。数值质量筛查可以在冻结后读取数据，但不得训练或比较预测分数来改选。

## 时间划分与信息边界

- BDG2：2016年为各站本地训练历史；仅development sites的2017 Q1–Q3滚动开发/校准；external sites 2017 Q4作为一次冻结外部评测。外部站点使用其2016历史按冻结算法训练，称跨站点方法迁移，非零样本迁移。
- RSF：2011-01至06训练，07至09开发/校准，10至12一次时间留出。仅一个站点，不能声称跨站泛化。
- OPSD：先按预定字段做质量/计量审查；最后完整90天为保留时间窗口，前至少180天为历史；不足则仅浏览/诊断，不参加主评测。
- UCI：沿用V2历史回归纪律。所有未来实测负荷、PV、天气、无功、CO2或分类标签均不得作发报时可用特征。历史天气不能冒充历史日前天气预报。
- 本数据任务不运行模型评测。模型/策略预算与胜出准则由核心独立冻结；首次评测前汇总数据哈希、配置哈希和代码哈希。

## 质量与计费资格

严格保留原始文件、source row、源时间、timezone、单位、计量边界、缺失/插补标记。允许用已知历史因果填充训练特征，但不把测试真值补成观测。规范化文件保留 NaN 并带 observed 标记。

完整月需量只允许原生15分钟数据，且月内每个实际区间都有有效原始非负进口目标；缺失、插补、重复未解决、时间语义未解决均不认证该月。确定时区数据用UTC唯一连续时间轴与本地计费月份；DST自然存在92/100间隔天。小时峰值、重采样插值峰值、部分月峰值均不是实测15分钟计费需量。

月度 coverage 报告各月期望/实有/原始观测行数与完整状态。用数据是否完整选择计费资格，不因负收益删除月份。scope 分别声明调度、能量计费、15分钟需量、光伏和拒绝原因。

## 声明与资源预算

全部为公共研究数据离线验证，不是客户实机/中国电费/商业ROI证据。海外数据套人民币示例电价时须显示假设计价。大CSV分块处理，计算串行、线程数1，避免全体数据长表常驻内存。第三方数据许可与软件许可分开保存；不得假称数据提供方背书。

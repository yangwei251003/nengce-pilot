## 已关闭的问题

- 私人CSV的90天最低数据与默认评估日期不一致：调整默认日期；合法导入到实际运行已经通过。
- 运行索引SQLite连接未及时关闭导致Windows文件锁：使用明确关闭的连接上下文；测试通过。
- 排队取消后的Future/取消标志残留：取消未启动任务时立即释放；新增回归通过。
- 模块导入误触发恢复程序可能中断另一服务：恢复移动到实际服务启动生命周期；独立进程导入不改状态，启动才标中断，新增回归通过。
- 侧栏键盘循环出现焦点离开弹窗：明确焦点边界，30次Tab真实复测通过。
- 图表窄屏宽度、正负功率/SOC刻度、字体和对比度：两轮截图修正，三视口检查留证。
- 助手事实标签误配、数字改名、日期遗漏、未请求参数被擅自加入：本机事实句/草稿范围校验已修复并测试；不因此宣称语义质量达标。
- 动画场景开始时间累计错误、费用柱错峰导致中间比较误导：修正时序和同步比例，保留失败渲染记录。
- PPT成本图非零起点、截图拉伸、Office形状负尺寸：已修正并重新原生打开/导出/审阅。

1. 免费助手存在过载、格式拒绝、漏答和上下文偏离，不能承担已验收的专业判断。单元测试和一次正确回答不替代50题业务门槛。
2. 外部BDG2学习预测没有击败开发选定的日朴素基线；不把局部胜出包装成整体泛化成功。
3. UCI负荷增加20%时N1出现真实终端不可达，整组公平比较失败。费用复算通过与可执行/可比较是独立状态。
4. R2在本批公开数据上没有优于R1的额外实证收益。RSF普通月的风险改善也未达到预设10%阈值。

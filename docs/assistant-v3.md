# V3 证据助手：实际实现与验收口径

## 执行边界

助手是可选的云端解释层。负荷与光伏预测、约束调度、回放和计费均由本机计算模块完成。没有网络或模型不可用时，工作台仍可运行本机计算；助手如实显示不可用，不生成假回答。

默认平台为智谱，固定模型 `glm-4.7-flash`。只有用户明确选中手动备选时才使用 OpenRouter 固定模型 `qwen/qwen3.8-27b:free`。程序不自动换平台、不自动换型号、不购买服务；手动备选在每次请求前核验公开模型目录的零文本单价并关闭服务提供方自动回退。免费模型仍可能受限流、平台过载、超时和日额度影响；凭据已配置不能等同服务在线。

密钥仅由后端从项目外部的用户指定文件读取。密钥、原始数据和客户文件不进入模型上下文。只有元数据中 `public_data` 严格等于布尔 `true` 的公开案例可以调用；导入的私人或客户数据默认拒绝外发。对话文本会去除常见电话、邮件、密钥格式。此措施不构成任意自由文本的全面匿名化保证，界面继续提示仅询问公开案例。

## 实际工具

`inspect_result` 仅能查询当前会话绑定的不可变结果：

| kind | 可查询内容 | 限制 |
|---|---|---|
| summary | 区间、选模、当前策略总费、裁剪、电池参数 | 不能代替完整风险或费用明细 |
| cost | 各策略总费、费用分项、进口峰值、后端费用归因链 | 吞吐代理单列，不是真实寿命或供电账单项目 |
| risk | 反送/SOC/功率裁剪、最大时段、吞吐、末SOC、回退、候选风险门槛和代价 | 累计裁剪不等于单时段裁剪或停电量 |
| forecast | 负荷与光伏模型、开发选模理由、误差、区间覆盖和评测身份 | 不把历史回归包装为全新盲测 |
| provenance | 来源、许可、时区、间隔及本次限制 | 未知时区继续保留未知 |
| daily | 指定日期的日内能量费与吞吐代理 | 不含月末一次计入的需量；默认最多7天，显式披露截断 |
| limits | 年度盈利、真实回本/寿命、设备认证、客户订单和故障标签的证据边界 | 说明本次运行未提供什么；不虚构零客户、收益保证或认证 |

`propose_parameters` 仅生成容量、功率、需量单价、风险余量倍数的参数草稿。新值必须来自当前或先前用户对相应字段的明确数值请求；模型附带的未请求变更会被剔除并提示，不能静默把需量单价或风险余量归零。当前只可靠支持显式阿拉伯数字及规定单位的草稿约束，模糊加大/减小或汉字数值需要澄清，不能宣传为任意单位的自动方案定容。

草稿总会显示实际旧值、新值、单位及“尚未应用/重算”。应用草稿必须经过工作台的正常参数/重算路径。工具不能访问任意文件、网络搜索、其他运行、系统命令或真实设备。

## 数值与内容验证

模型决定查询什么并组织自然语言，工具返回带 `fact_id` 的事实。回答中全部业务数字（含日期）必须来自本地事实；后端核验引用存在后，直接用原始“策略＋指标＋数值＋单位”生成事实句和可点击定位信息。包含事实引用的句子不发布模型附加的标签、日期、数字或解释；独立的定性句可保留并另行验证。这防止正确的数值引用被改名为另一策略的收益，同时不丢失“不能全部归因AI”等独立否定句。

无引用数字、不存在的事实，以及已识别的累计/单时段混用、收益保证或未经核实的归因组合会被拒绝。格式错误可在限定轮数内纠正，最终失败明确显示错误。这些规则不构成对任意自然语言的完整语义证明。

格式门禁不能替代业务语义审核。相同数字也可能被贴错标签，因此验收除了检查引用，还必须逐题核对策略、计费范围、时段、比较基线、负结果和推论。拒绝未经核实回答属于安全行为，但不算正确完成问答。

引用归属按实际证据确定：运行级预测评测、选模、来源、配置与限制的 `strategy` 为 `null`；不会把全局 HGB 模型贴到 N1 周朴素策略上。单策略指标保留实际策略；学习增量明确标为 `N1 − L1`，归因链明确标为 `B0 → B1 → N1 → L1`。补充的 `scope`、`compared_strategies` 只描述归属，不改变原结果或已有引用字段。

每个会话绑定运行编号与结果哈希。服务端只读取该会话已保存的历史，客户端不能伪造先前助手消息。请求可取消；取消后到达的模型回复不发布。恢复和切换运行由实际API管理，旧运行证据不会混入新的运行上下文。

## 当前验收记录

冻结的50题保存在 `tools/evaluate_assistant.py` 的 `QUESTIONS`。原始失败与过载记录保存在 `qa/v3/assistant-live-suite-01`、`-02`、`-03`，不删除、不覆盖；旧版测试发现工具导航不清、错误选择summary、引用格式不稳定及平台过载。

修订版增加明确工具导航、光伏证据、风险门槛/代价、日内账单范围/截断，以及可定位的格式纠错。第二轮真实测试发现“引用数值正确但策略标签错误”，原始回答及业务FAIL保存在 `qa/v3/assistant-revision-02-independent-review.json`。后续又发现未请求的草稿附加值与独立否定句丢失。相应机制已经修复，25项本机单元测试通过，记录为 `qa/v3/assistant-unit-final-frozen.log`。这些单元测试不替代真实模型业务测试。

逐轮真实测试、模型回复轨迹、源结果哈希、助手与平台代码哈希及协议保存在 `qa/v3/assistant-live-revision-03`、`assistant-final-live-tail`、`assistant-final-retest-01` 与 `assistant-final-retest-02`。最后一轮让出免费平台并发给真实浏览器验收后停止；未执行题保持NOT RUN。

随后在一个固定代码版本上发起了正式50题顺序回归，记录在 `qa/v3/assistant-final-frozen-50`。宿主中断后仅继续未执行题，原前10题和源码/数据哈希核对记录全部保留。第14、15、16题连续平台HTTP429/1305后停止：实际尝试16题，人工业务审阅 **6 PASS、3 FAIL、7 BLOCKED，另外34题NOT RUN**。业务正确为6/16次尝试；7条非空已发布答案中的19个数值引用均与冻结源结果相符，但第11题全局模型引用策略归属错误，因此引用归属正确仅6/7。完整95%业务门槛及数字/引用100%门槛均未通过。第3题为证据/格式拒绝，第10题为MemoryError，第11题为引用归属错误；不将平台阻塞计成正确答案。

第11题暴露的确定性引用归属缺陷已在后续版本修复，并复核全部工具字段归属；全量29项助手本地测试PASS，见 `qa/v3/assistant-unit-scope-fix.log`。最终修复后没有再调用模型，**修复版线上50题为NOT RUN，可用性仅有修复前BLOCKED的观察记录**。旧正式轮次成绩保持不变，不能用本地测试、早前开发成功或修复声明替换真实业务验收。完整汇总见 `qa/v3/assistant-acceptance-summary.json`，报告见 `qa/v3/assistant-acceptance-report.md`，正式逐题审阅见 `qa/v3/assistant-final-frozen-50/business-review.csv`。此50题是开发回归，不是全新独立能力基准；核对由开发QA代理完成，不能称为独立客户或盲测评审。

状态约定：PASS为实际执行并满足所列验收条件；FAIL为功能/回答未满足；BLOCKED为外部模型不可用；NOT RUN为未实际执行。平台错误不计作正确答案，重试成功也不删除先前失败。

# V3 核心计算与冻结算法预算

版本建立：2026-10-04；在任何新来源留出模型评估前写入。UCI 2018年12月已公开，只用于工程开发和历史回归。

## 实际接口

`backend.v3.config.RunConfig` 继承原电池与评估配置，新增 `tariff.prices`（24或96项）、`tariff.demand_per_kw`、`protocol_id`、`pv_drop_30` 压力情景。计费身份固定 `illustrative`。

`backend.v3.core.run_experiment(config, run_id, progress=None, cancelled=None)` 返回 schema 3.0.0。保留 V2 主结构，新增同站PV预测、15分钟间隔、弃光、R2、月账、终端修复与完整性状态。`summary.hours` 为真实小时数，`intervals` 才是记录数。缺需量资格时 `demand_cost/total_cost/savings_vs_b0` 为 null，已知能量与吞吐代理放在 `known_cost_subtotal`，禁止把缺费当0。

## 固定预测预算

仅一个 HGB 参数组合：140次迭代、15叶、学习率0.07、L2=10、seed=42、不提前停止。三开发窗口，对比日前朴素和周朴素；学习模型需比开发期最优简单基线 MAE 至少改善2%，且至少赢2/3窗，否则回退简单基线。负荷、PV各自选择；无PV计量就保留零PV身份，不生成假光伏。

允许特征仅为日历、24/48/168/336小时过去负荷或PV、前一完整日均值/最大值、过去七日均值。DST 25小时日会侵入当天的24h lag改用48h lag，保持日初信息边界。缺失历史只在特征中因果前填，不补测试真值。区间为开发残差绝对值q90，风险余量为所选负荷预测正残差q75、上限预测净负荷35%。无未来天气、无功、CO2、Load_Type。

RSF采用冻结元数据的1–6月训练、7/8/9月三个开发窗、10–12月留出；三窗均不把7–9月样本重新加入训练。BDG2开发站点也严格只用2016拟合，2017Q1/Q2/Q3作为三个顺序验证窗；按所有开发站点的总样本加权MAE及逐窗合并成绩选择一个共同模型，外部站点不参与选择。简单基线并列时选周朴素。外部各站再用其2016拟合固定配置HGB，完整Q4仅评分一次。同站临时选择仍标探索，不冒充外部验证。

跨站区间/风险校准：先在各开发建筑用其2016平均负荷归一化残差，计算所选共同模型的绝对q90和正残差q75，再取12栋开发建筑相应分位数的中位数。外部站的尺度仅用该站2016平均负荷恢复kW；不是有统计覆盖保证的区间。该规则在首次新来源模型评分前固定，零超参搜索预算。缺失外部真值不评分且公布覆盖比例；全建筑及负结果保留。

## 物理与优化

MILP显式变量：AC充/放功率、末电量、充电二元状态、弃光、电网进口、余量释放、月峰值。时间间隔dt贯穿能量守恒、效率、电能费和吞吐费。求解返回后独立检查矩阵、上下界、整数状态与软余量预算，不能把求解器状态直接当有效。

禁止反送电与同时充放电；剩余PV弃光。实际SOC跨日延续，共同日末目标为初始配置SOC。末区间各电池策略可使用当前实测量执行共同物理修复，记录修改的AC能量；不能凭空放电或重置SOC，失败保留为无效比较。

B0无储能，B1固定峰谷，N1周朴素，L1固定HGB，B2开发所选模型，O1逐日未来实测诊断，R1固定安全余量，R2终端可达余量预算。O1不是整月联合最优下界，不可部署。B2/N1/L1/R1/R2每区间滚动重解，只执行首动作；因果误差校正为上一已完成间隔误差的0.5倍、6小时指数衰减。

R1先尝试硬余量，失败从相同实际SOC按原物理约束回退，科学候选仍判失败。R2硬余量不可行时先严格最小化释放的AC余量，再在该最小预算下优化费用；不得释放物理约束。发布候选门槛为裁剪至少减少10%、保留至少90%节费和80%吞吐、物理/终端/最终求解有效；R1还需无余量失败。R2允许记录在案的最小余量释放。零基线裁剪时不把无法定义的比例计为通过。默认推荐保持B2，留出评估不自动改赢家。

## 月度计费与独立复算

每策略独立保存本月已经发生的实际峰值，日内计划仅优化相对它的新增预测峰值；只在月账结算一次。完整原生15分钟、原始观测齐全才计算示例需量。UTC存储按已知源时区日历计价，DST月份期望区间数据实计算；未知UCI时区按source-local示例月，不宣称真实韩国合同。小时或部分月请求需量时完整账单为null。

供电账单=`电能费+需量费`；吞吐衰减代理单列，总情景费用再加代理。无售电、税费、阶梯、合同需量罚金、进口限额或真实寿命/ROI。每日卡片只显示电能+吞吐，月费在月账呈现。日前计划费用是每天起点预测目标之和，与回放差不是“裁剪损失”。

# 数据边界修订 02：符号与累计表（评测前）

2026-10-04，尚未对新留出运行模型。

RSF源PV(kW)使用负号发电，4146条负值；21条小正值代表该有符号通道净耗电而非发电。原文件逐点满足 Building Net = Total Building + signed PV，最大闭合差0。转换采用 pv_kw=max(-signed PV,0)，load_kw=电气分项和+max(signed PV,0)，净流严格保持原值，不把负发电当坏值或抹去辅助耗电。电气分项和与Total Building-Heating-Cooling最大4kW差保留，不能称整楼电表闭合。早期规范化草稿在未评测前修正，原始文件和冻结协议不变。

OPSD发布15分钟文件各数值列仍为累计kWh寄存器。必须相邻寄存器相减再除0.25小时。规范化行t记录(t,t+1)差分并保留source_row/source_row_end及原寄存器；双端点插补、缺失、复位均进入观测资格。该处理只供通道诊断，没有完整原站无储能总负荷、出口与既有DER边界的证明，不开放调度或电费收益。

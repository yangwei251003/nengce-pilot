# 能策 Pilot V3 / 界面设计约束

用户是能源服务商的方案工程师。主任务是审查一份站点数据，在统一计费口径下看清计划、执行、费用和风险，再导出可复算证据。

## 视觉

- 暖白工作底色 `#f7f8f3`、纸面 `#fffefa`、深林绿 `#204833`；少量浅黄绿强调实际主操作，琥珀色显示不确定性，砖红显示不利结果。
- 中文使用本机 Microsoft YaHei UI / PingFang SC，数字用本机 Segoe UI 的等宽数字特性；没有在线字体依赖。
- 正文 14px、辅助文字 12px、标题 25–30px。主图与判断先于长说明；数据表按单位对齐，缺失值用“—”，不替换成 0。
- 桌面顶栏与简短页签导航；工作台主图配判断/证据侧栏。窄屏单列，参数/助手为模态侧栏。宽表格局部滚动。
- 动效只表现界面状态切换，不伪装实时遥测或模型流式输出。减少动态效果偏好禁用过渡；进度只读后端阶段。

## 信息层级

主工作台：运行上下文 → 结论与费用摘要 → 多轨联动时序 → 每日风险定位 → 必要的证据。

参数是可审阅的草稿，与不可变运行配置区分。助手建议只能生成参数草稿，由用户检查并运行；引用可定位数据、策略、日期及证据。私人数据默认不外发。

## 组件与接口

按职责拆分状态与 API、主图、目录与导入、费用、历史、参数、助手和证据；不保留巨型单行组件。

接口统一经本地 `/api/v3`，开发阶段可回退兼容 `/api`；助手异步轮询，禁止浏览器直接请求模型服务。无成功结果时仅展示真实待计算状态。
